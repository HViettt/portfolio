Kiến trúc AI đa tầng (Multi-tier Fallback)
Vấn đề: Người dùng cá nhân quá tải công việc, khó phân loại độ ưu tiên tối ưu và hệ thống dễ gặp lỗi khi gọi API AI của bên thứ ba (lỗi giới hạn yêu cầu, lỗi mạng).

Khi phân tích task: Ưu tiên AI chính (OpenAI/Gemini) ➔ Lỗi tự động chuyển sang AI phụ (Local AI / Server-side model) ➔ Lỗi tiếp tục tự động dùng heuristic algorithm (logic tính điểm dựa trên deadline + lịch sử công việc) để luôn trả ra kết quả mà không làm chết ứng dụng. Xây dựng background job bằng node-schedule để tự động xử lý trạng thái task quá hạn mỗi 30 phút.
Kết quả / Điểm nổi bật: Hệ thống hoạt động hoàn chỉnh với khả năng chống lỗi (fault-tolerant) cao cấp. Tích hợp Toast notification chuẩn WCAG 2.1 AA phục vụ người khuyết tật, đa ngôn ngữ thời gian thực (i18n), quản lý trạng thái mượt mà bằng Zustand.

VinFast Showroom Management System – Triển khai trên AWS

Full-stack Web App deployed on AWS with Docker
Vấn đề: Cần triển khai một hệ thống showroom ô tô full-stack theo mô hình client-server tách biệt, đảm bảo khả năng chạy ổn định trên môi trường production và bảo mật tốt khi vận hành trên cloud.
Giải pháp kỹ thuật: Tự triển khai frontend ReactJS (SPA) và backend Node.js/Express.js với JWT authentication và phân quyền theo vai trò user/admin. Dùng MongoDB Atlas làm database-as-a-service, đóng gói frontend/backend thành các container riêng bằng Docker và Docker Compose, đồng thời triển khai lên Amazon EC2 theo mô hình multi-container. Tích hợp AWS IAM Role thay vì lưu credential trực tiếp trong mã nguồn, cấu hình Security Group theo nguyên tắc Least Privilege, dùng SSM Session Manager để quản trị instance qua trình duyệt và triển khai upload/xóa ảnh sản phẩm qua Amazon S3 + AWS SDK for JavaScript v3 + Multer. Giám sát CPU, memory và trạng thái instance thông qua Amazon CloudWatch.
Kết quả: Hệ thống chạy ổn định trên EC2 với cấu hình bảo mật đúng chuẩn Least Privilege, không mở SSH công khai và không hardcode credentials. Quá trình deploy đạt được tính nhất quán giữa local và production, đồng thời hỗ trợ giám sát hệ thống và quản lý instance từ xa hiệu quả.

Amazon EC2: Khởi tạo Ubuntu Server 22.04 LTS trên instance type m7i-flex.large (2 vCPU, 20GB SSD). Security Group chỉ mở port 22 (SSH, giới hạn IP) và port 80 (HTTP public), giảm attack surface.

AWS IAM: Thiết lập IAM Role trực tiếp gắn cho EC2 thay vì lưu Access Key/Secret Key trong source code, đồng thời cấp các policy cần thiết như AmazonS3FullAccess, CloudWatchAgentServerPolicy và AmazonSSMManagedInstanceCore.

AWS Systems Manager: Cấu hình Session Manager để quản trị EC2 từ trình duyệt, mã hóa hoàn toàn, không cần mở SSH công khai.

Amazon S3: Tích hợp AWS SDK for JavaScript v3 và Multer vào backend để upload/xóa ảnh sản phẩm, lưu URL ảnh trong MongoDB để hiển thị lên website.

Amazon CloudWatch: Giám sát log và metric hệ thống sau khi deploy, theo dõi CPU, memory và trạng thái instance.

Docker & Docker Compose: Đóng gói frontend và backend thành các container riêng biệt, viết Dockerfile riêng và dùng Docker Compose quản lý multi-container. Frontend chạy trên Nginx để phục vụ production hiệu quả.
