SmartTask

Kiến trúc AI đa tầng (Multi-tier Fallback)
Vấn đề: Người dùng cá nhân quá tải công việc, khó phân loại độ ưu tiên tối ưu và hệ thống dễ gặp lỗi khi gọi API AI của bên thứ ba (lỗi giới hạn yêu cầu, lỗi mạng).
Giải pháp kỹ thuật: Thiết kế thuật toán AI Fallback đa tầng. Khi phân tích task: Ưu tiên AI chính (OpenAI/Gemini) ➔ Lỗi tự động chuyển sang AI phụ (Local AI / Server-side model) ➔ Lỗi tiếp tục tự động dùng heuristic algorithm (logic tính điểm dựa trên deadline + lịch sử công việc) để luôn trả ra kết quả mà không làm chết ứng dụng. Xây dựng background-job bằng node-cron để tự động xử lý trạng thái task quá hạn mỗi 30 phút.
Kết quả / Điểm nổi bật: Hệ thống hoạt động hoàn chỉnh với khả năng chống lỗi (fault-tolerant) cao cấp. Tích hợp Toast notification chuẩn WCAG 2.1 AA phục vụ người khuyết tật, đa ngôn ngữ thời gian thực (i18n), quản lý trạng thái mượt mà bằng Zustand.

E-Commerce Management

Layered Architecture (Controller-Service-Repository)
Vấn đề: Cần quản lý hàng hóa, đơn hàng lớn phức tạp, phân quyền chặt chẽ giữa Quản trị viên (Admin) và Nhân viên, đồng thời xuất báo cáo nhanh chóng.
Giải pháp kỹ thuật: Thiết kế kiến trúc phân tầng chuẩn Hibernate/Spring Data JPA giúp xử lý cơ sở dữ liệu MySQL ổn định. Triển khai phân quyền phân vai dựa trên Spring Security & JWT Token. Xây dựng bộ lọc, phân trang phía cơ sở dữ liệu để tối ưu lượng dữ liệu truyền qua mạng, và tích hợp export CSV báo cáo.
Kết quả: Chứng minh khả năng lập trình Fullstack đa hệ sinh thái ngoài Node.js (sử dụng hệ sinh thái Java doanh nghiệp). Dashboard trực quan, bảo mật đầu cuối.

Backend được quản lý bằng Maven. Sử dụng Spring Boot Starter Web và Data JPA để ánh xạ thực thể cơ sở dữ liệu. Dùng Spring Security bảo vệ toàn bộ API Endpoint, ngăn chặn các tấn công cơ bản. Frontend giao tiếp qua RESTful APIs, biểu diễn lượng hàng tồn và doanh thu thời gian thực qua Chart.js.

Vietnam Travel Guide

Tự phát triển kiến trúc MVC bằng PHP (Không dùng Framework)
Vấn đề: Xây dựng blog cộng đồng chia sẻ thông tin mà không dùng các framework nặng có sẵn, đòi hỏi hiểu rõ cách web server nhận request, parse URL và điều hướng (routing).
Giải pháp kỹ thuật: Tự viết router xử lý request (lấy URI chuyển thành Controller/Action cụ thể). Tự triển khai session lưu trữ xác thực đăng nhập, cơ chế gửi email xác nhận đặt lại mật khẩu, cấu trúc cơ sở dữ liệu MySQL lưu bình luận dạng lồng nhau (nested comments) cho blogger.
Kết quả: Đóng vai trò là dự án nền tảng. Việc tự viết MVC giúp hiểu sâu sắc vòng đời HTTP Request, cách xây dựng middleware và cơ chế bảo mật (như phòng chống SQL Injection) ở mức lõi hệ thống trước khi tiếp cận React/NodeJS.

Hệ thống hỗ trợ tải ảnh trực tiếp qua Cloudinary API. Hệ thống bảo mật đăng ký qua email kích hoạt tài khoản. Phân quyền Admin có đầy đủ dashboard thống kê biểu đồ động biểu thị số lượng bài viết, lượt đăng ký blogger tăng trưởng theo năm bằng biểu đồ HTML/CSS canvas thuần.
